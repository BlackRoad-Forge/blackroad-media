# BlackRoad OS Brand Assets

Official brand assets for BlackRoad OS, Inc. — **Road. Pave Tomorrow.**

## 📁 Structure

```
assets/
├── logos/          — Official logos (PNG, transparent variants)
├── mascots/        — Roadie mascot character art
├── hq/             — BlackRoad HQ scenes (pixel art)
├── pixel-art/      — City, campus, office scenes
└── icons/          — App icons and UI icons
```
